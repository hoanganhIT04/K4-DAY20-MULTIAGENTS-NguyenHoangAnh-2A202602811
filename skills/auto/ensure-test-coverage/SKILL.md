---
name: ensure-test-coverage
description: Use when modifying code to guarantee that all changes are adequately tested.
---
- Create new test cases for every bug fix or feature addition.
- Ensure that tests are placed in the appropriate test files without modifying existing tests.
- Aim for at least three tests for each significant change to validate functionality.
- Run the test suite after every change to confirm that all tests pass.
- Document the purpose of each test case clearly to facilitate understanding.
- Use code coverage tools to identify untested parts of the codebase.
- Regularly review and refactor tests to keep them relevant and effective.
- Collaborate with team members to ensure comprehensive test coverage across the codebase.
