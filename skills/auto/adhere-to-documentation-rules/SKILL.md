---
name: adhere-to-documentation-rules
description: Use when implementing functions to ensure compliance with documentation standards.
---
- Review the function's docstring before implementation to understand expected behavior.
- Ensure all public functions have type annotations for parameters and return values.
- Validate that the implementation matches the examples and descriptions in the docstring.
- Add or update tests to cover all edge cases mentioned in the documentation.
- Maintain a CHANGELOG.md to document all changes made, following the specified format.
- Regularly check that all rules and conventions outlined in the documentation are being followed.
- Conduct a peer review of the code to ensure adherence to documentation standards.
- Use automated tools to verify compliance with documentation rules where applicable.
